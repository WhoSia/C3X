# Patches

C3X uses a patch-overlay model before any full-engine fork is authorized.

Every promoted patch family should bind:
1. exact upstream repository + ref;
2. pre-patch source identity;
3. exact patch bytes;
4. post-apply identity;
5. build recipe;
6. regression receipt.

Do not place reconstructed historical patches here merely to make the repository look complete.

The first new active patch family is reserved for G9.4-P12.
