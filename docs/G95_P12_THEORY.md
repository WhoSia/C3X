# C3X 0.7.0-G9.5-P12 — Exact-Cutoff Mediation in Chess Search\n\n## 1. Return to chess\n\nC3X began with a chess question, not a telemetry question:\n\n> Why does an engine prefer one near-equal legal move over another, beyond merely reporting the best move?\n\nP12 therefore treats alpha-beta windows, transposition-table cutoffs and re-search as useful only when they explain a concrete chess consequence: a legal candidate branch survives, disappears or replaces another branch in the principal variation or at the root.\n\nThe terminal object is not a cutoff taxonomy. It is a falsifiable path from one exact search intervention to a changed candidate-move fate.\n\n## 2. Parent result\n\nP11 replayed 17/17 inherited move-order witnesses exactly. Every witness showed a downstream CUTOFF divergence, but coarse P34-Q3 cutoff-class removal aligned with the target root transition in only 4/17 and redirected in 11/17.\n\nThus P11 established a common downstream locus without a common mediation law.\n\nP12 asks whether the missing object is not the class CUTOFF, but a particular exact cutoff transition.\n\n## 3. Fresh worlds\n\nP12 uses April, May and June 2026 Lichess official broadcasts. For each source, exactly the first 1,024 games are inspected. Eligible late-opening positions retain the P10 constraints: plies 14–21, standard legal chess, nonterminal, not in check, 18–48 legal moves, and absolute material imbalance no greater than three pawns.\n\nAll recoverable P1–P11 candidate hashes and cross-source duplicates are excluded before selection. Four positions are chosen per source by deterministic trajectory hash order, yielding 12 positions × 3 engines = 36 worlds. No engine outcome is consulted during position selection.\n\n## 4. Frozen upstream target\n\nWithin each baseline trace, P12 admits only MOVE_ORDER_SEED events satisfying the already earned P10/P11 skeleton: MAIN; ply 1; depth 5–8; repeated full TT key; same TT move as the most recent same-key occurrence; LOWER or UPPER bound.\n\nAt most 16 events per world are selected by exact address-id order. This selection uses the baseline trace only. Root-change outcome is not part of target admission.\n\n## 5. From one cutoff class to one cutoff transition\n\nFor each target whose exact removal changes the root move, P12 compares the downstream CUTOFF streams. The first post-target divergence is frozen as a pair: B is the baseline-side exact cutoff that disappears or is replaced; C is the T_ONLY-side exact cutoff that emerges or replaces B. Either side may be absent.\n\nP12 does not skip a failed pair and search later for a more favorable cutoff.\n\n## 6. Window and re-search anatomy\n\nEvery published cutoff diagnostic contains ply and depth; alpha and beta; window width; NULL / NARROW / WIDE window class; TT value and bound; fail-high / fail-low / inside-window relation; TT-move presence; prior same-key count; prior same-key window/depth state; and distance from the upstream target.\n\nWithin one trace, a later same-key/same-ply event following a NULL or NARROW window with a strictly wider window, or a changed fail/window relation, is recorded as a re-search/PVS proxy. This is an operational search-path observable, not a claim that every engine implements identical PVS control flow.\n\n## 7. Exact intervention arms\n\nFor each fresh ROOT_CHANGE target: BASE; T_ONLY removes the exact upstream MOVE_ORDER_SEED event; B_ONLY removes the exact baseline-side cutoff B when B exists; T_PLUS_C removes T and the exact counterfactual-side cutoff C together when C exists.\n\nThis separates baseline-cutoff sufficiency from counterfactual-cutoff necessity.\n\n## 8. Mediation verdicts\n\nEXACT_CUTOFF_BRIDGE: B_ONLY reaches the T_ONLY root move and T_PLUS_C restores BASE.\n\nBASELINE_CUTOFF_SUFFICIENCY_ONLY: B_ONLY reaches T_ONLY, but T_PLUS_C does not restore BASE.\n\nCOUNTERFACTUAL_CUTOFF_NECESSITY_ONLY: T_PLUS_C restores BASE, but B_ONLY does not reproduce T_ONLY.\n\nEXACT_CUTOFF_INTERACTION_REDIRECT: an exact cutoff intervention creates a third legal root move.\n\nCUTOFF_COLOCATION_ONLY: the exact pair exists, but neither side earns sufficiency or necessity.\n\nNO_EXACT_CUTOFF_PAIR / ADDRESS_DRIFT: the frozen transition cannot be tested exactly.\n\nNo later-event rescue is allowed.\n\n## 9. Chess-native diagnostic\n\nFor every positive witness, the public record must show source-game ply; legal root move count; baseline and T_ONLY root moves in UCI and SAN; B_ONLY and T_PLUS_C root moves when executed; capture/check/castling/promotion flags; first PV divergence and legal SAN prefix when recoverable; B and C window/fail/revisit anatomy; and a short branch-replacement statement grounded only in those verified facts.\n\nThe intended developer question is: Which legal root candidate replaced which other candidate, and which exact TT cutoff transition was sufficient or necessary for that replacement under this search regime?\n\n## 10. Harvest donors, translated back into chess\n\nP12 borrows four methodological ideas without importing their jargon as ontology: explanation requires intervention-sensitive dependence; experiments should separate live rivals rather than merely gather more traces; residual mismatch does not uniquely identify its cause; and non-identifiability under an explicit intervention set is a positive result.\n\nIn chess terms, a cutoff is explanatory only if exact manipulation changes the candidate-move fate in the predicted way.\n\n## 11. Replication\n\nA transition signature is: bound sign + B fail/window/revisit state + C fail/window/revisit state + mediation verdict.\n\nA signature is called replicated only if it contains at least 3 fresh root-change witnesses, at least 2 engines, at least 2 positions and at least 2 monthly sources. No signature is refined after seeing outcomes.\n\n## 12. Stop rule\n\nP12 ends after the fresh experiment, exact transition adjudication, chess-native diagnostic and bounded patch-stability report.\n\nIf exact cutoff mediation fails, the correct conclusion is that P11's common cutoff locus remains a search-reorganization marker rather than an identified mediator. The next stage may then return to root-candidate search dynamics rather than inventing another cutoff taxonomy.\n
