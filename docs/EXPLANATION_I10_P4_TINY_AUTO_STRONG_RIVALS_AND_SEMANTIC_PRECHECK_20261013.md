## A. Original-source implementation and experimentally checked result
- [Trainable 9-weight listwise linear claim router](../c3x_explain/ecl_tiny_selector.py): Python stdlib only, 3 question classes × 3 admissible evidence claim roles. Trains by listwise softmax SGD (100 iterations, learning rate .35). The output can only be an existing compiled source claim ID; no new chess evaluation, probability or causal statement. Model artifact includes canonical SHA256, train groups, training count and hard game-disjoint evaluation guard. Only 9 trainable scalars, not an LLM and not an independent chess strategy predictor.
- [Preoutcome PGN automatic moment ranker](../c3x_explain/ecl_auto.py): selects by check/capture/castling/promotion and earlier move tie-break **before engine analysis**, max five source trial positions per exposed development game; then original SF16 scout depth9 distinct played-move rival, restricted pair depth12, I9/I10 chain and P3 source claims. Counts every eligible ply and every attempted/abstained result. Changes *none* of legacy I9 automatic selector logic/receipts.
- [Actual exposed-history, whole-game-split pilot](../tools/c3x_explain_i10_p4_trainable_auto_equal_evidence_pilot.py): train only on fixed Kasparov–Topalov 1999 game, evaluate only on fixed Morphy Opera 1858 game, but both games already seen in previous research; synthetic/structural weak supervision generated automatically from source-authorized claim roles. **Not human labels, no independent new position ecology.**
