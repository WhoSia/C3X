## 3. What could be **truly more rigorous**, and what would prove it?

Proposed scientific distinction: **C3X separates (1) legal chess-world property, (2) public engine choice/score/PV, (3) exact original source event causally governing a bounded choice, and (4) human-interpretable natural-language justification, each with separately auditable authority ceilings**. This is a *research architecture* and a **single existing partial source-native historic demonstration**, not a proven universally better explanation system.

**Necessary result A — source-causal precision**: preregister newly sampled independent nonterminal games with at least one actual original executable source event and a true SHAM/source mutation. Compare C3X proof-carrying claims vs Queen, published CCC, Cui partial-strategy, KibitzAI, SHAP and verified strong score+PV narration. Report `conditional false attribution rate`, `precision at fixed coverage`, and `abstention calibration`, with unique chess games as cluster units. **All competitors receive the same source trace in a separate equal-information arm**, so C3X does not win simply through privileged access.

**Necessary result B — chess-concept discriminative truth**: independently adjudicated meaningful motives (blocked d-file, king safety, rook coordination) must correspond to actual variation classes; swap/challenge the proposed motif while retaining legality and record whether preference/event source changes. A local source TT causal witness `!=` a meaningful rook-coordination explanation.

**Necessary result C — human understanding**: evaluation must include real blinded participants, opponent-reply counterfactuals *outside the shown PV*, post-explanation action correctness on withheld positions, and strength-stratified comprehension. Queen/Cui/Schut already attack explanatory utility. If C3X improves only verbose documentation but not understanding, usefulness superiority fails.

**Necessary result D — fair model-level ability**: source-equal under frozen LLM, token, compute and rating setting. Queen's reported grandmaster Elo cannot be compared to Stockfish-assisted PGN reporter. Move quality/accuracy and fluency are secondary but **must not collapse**.

A winning original claim might be *“under independently frozen nonterminal positions, C3X explanations reduce unsupported source-mechanism attributions at matched nontrivial coverage, and the same mechanism-explanation components improve novel opponent-response decisions beyond the best concept/tree/LLM baselines”*. **This precise conjunctive result has NOT been demonstrated.** Until it is, claim `ORIGINAL_SOURCE_SCOPE_CERTIFICATE_AUTHENTICITY_AUDITED`, not `ACADEMICALLY_SUPERIOR_TO_ALL_PRECEDENTS`.
