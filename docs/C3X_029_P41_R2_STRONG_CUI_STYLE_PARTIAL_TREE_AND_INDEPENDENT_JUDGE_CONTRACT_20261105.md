# C3X P41/R2 — Non-Substitutable Competitor and Referee Admission Contract
Date: 2026-11-05 KST. Prepared after reading primary PDFs of Cui (2026), Press & Golubev (2026), ACT-Eval (2026), QUEEN (2026), Schut (2025), Jenner (2024), Geiger (2025), and related archival sources. NOT A NATIVE CHESS STUDY.

## Main correction from Cui et al.
A single Stockfish one-line PV is NOT the strongest prior-art baseline for strategic verbalization. Cui et al. (Findings EMNLP 2026) serialize a partial strategy tree branching on the top k_strat=3 opponent responses, and evaluate through tree-expanded puzzle playing using k_eval=3 adversarial responses per opponent node. Their algorithm explicitly considers off-main-line responses and human utility. Our P37 'PV beat C3X shallow material' result is still an honest negative, but a *P41 strong baseline* must include their type of partial-tree baseline at equal **actual consumed computation**, not only one-line PV.

## Four mandatory prespecified competitors
B0: raw same-root Stockfish source-pinned score + one PV, with exact observed nodes/time. B1: **Cui-style k_strat=3 partial engine strategy tree**, including legal opponent branches and best own response, cost metered per engine call/branch. B2: BinProp/CCC-inspired *source-verifiable typed concept rules* with fixed plan length/output cardinality and no labels/ground truth supplied. B3: C3X source-grounded plan predictor. No-plan/abstain can serve as a separately scored conservative rival. They must predict the SAME target Q/plan regret under the SAME allowed resource limit. Output language is not the score.

## Shared budget account
Budget vector, not just one number: total native engine nodes consumed, number of independent engine queries, wall-clock and CPU, legal-move expansions (own and opponent), number of language-model tokens/API calls if used, number of plan predicates/response-conditioned claims, and abstention/coverage. Controlling 24k Stockfish per method while permitting the C3X method 25k extra legal expansions without charging for them is NOT a fair comparison. Baseline B1 consumes far more than one PV when queries per branch are counted; either reduce all under a global budget or report a Pareto frontier rather than falsely equalizing costs.

## Source / judge / truth separation
For each original game, source bytes SHA + full UCI legal mainline + event/game disjointness must pass BEFORE candidate selection. Plan predicates P(s,m,r) and forecasts must be committed in a sealed artifact BEFORE reference judge J outputs. The judge must not use C3X labels as ground truth. Same Stockfish family scores only give **engine-family consistency**, not objective chess value. An independent referee must have version/source/binary/network checksum, *actual* work/nodes and a successful dry-run protocol gate; prior P38 Ethereal did not meet this gate. Judge disagreements or score intervals overlapping => ABSTAIN rather than invented move superiority.

## Anti-triviality
Reject P(s,m,r)=all legal continuations for any claimed universally selective plan. Also reject the loophole 'exclude only one impossible/worst move after seeing judge score', even though mathematically P is a proper subset. Require a SOURCE-FROZEN plan predicate (semantic field, argument schema, bounded complexity) selected before any judge labels; record and cap planned fraction for each tested opponent reply (e.g. <=1/2 where possible; choose exact prior threshold before data). If no legal own reply can satisfy P after some r, label PLAN_BREAK (not zero regret). If near-tie root candidates disappear/reorder at higher source-pinned budgets, report failure and retain them in denominator, rather than posthoc replacing cases.

## Primary score and falsification
Primary future value claim: J-evaluated plan-regret interval for each considered legal opponent reply and robust aggregation; measure calibration / outcome loss against explicit B0-B3 forecasts, stratified by stable near / intermediate / wide and report source-event-blocked uncertainty. The all-response universal LOW-regret certificate is distinct from finite k_eval sampled test: sampled can REFUTE using a counterexample but cannot PROVE universal goodness. The precommit must fix number of cases, query budgets, significance/decision thresholds and base rates before any J labels. Any 'C3X beats B0 but not B1' result is not novel partial-strategy information.

## Fatal source-check
No source-verified independent J => technical HOLD, not a fake paper. No source-disjoint cases => development analysis only. Only genuine 4-way equal-cost comparison with factual/law certificates, calibrated abstention and source-faithful neural intervention can support the requested flagship conjunction.
