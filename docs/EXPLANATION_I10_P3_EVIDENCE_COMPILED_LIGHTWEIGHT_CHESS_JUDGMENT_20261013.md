## 2. Precise practical architecture

Historical I9 verified PGN/atom/commentary; I10 source-bounded root-rival decision; I10-P2 historic Ethereal **LOCAL_ONLY** certificate still NOT publicly admitted. New I10-P3:

```
PGN / source UCI PV / bounded cp / board
       │
       ▼
I9 factuality/provenance/realization firewall
       │
       ▼
I10 exact played-versus-rival score and legal PV
       │
       ▼
I10-P3 EvidenceCompiler
  - verifies FEN legality and original move identity
  - recomputes I10 judgment (rejects caller-spoofed external packet)
  - binds every claim to existing atom IDs
  - extracts only bounded source rank and replayed PV facts
  - withholds forged graph 'causal certificate' nodes
       │
       ▼
Tiny 0-trained-parameter static claim ranker
  - only chooses from already admitted claim IDs
  - cannot issue causal authority, fabricate move or score
       │
       ▼
Korean literal renderer
  - same evidence/authority, no forced-opponent invention
  - natural-language model later, bounded by verifier
```

[Code](../c3x_explain/evidence_compiler.py), [12 targeted adversarial tests](../tests/test_c3x_explain_i10_p3_evidence_compiler.py), [CLI `--ecl-json-out` and `--ecl-markdown`](../c3x_explain/__main__.py), [native exposed-case script](../tools/c3x_explain_i10_p3_native_ecl_pilot.py), [read-only CI](../.github/workflows/c3x-explain-i10-p3-ecl-compact-compiler.yml).

**A typed record is not a neural network.** This implementation is an actual working zero-training source-evidence compiler and a **static tiny selector interface**, NOT a fitted small judgment model. No probabilities issued or made up, no new semantic causal source claim. The contemporary I9 graph can contain a certificate-shaped node in tests: source node presence is NOT byte-level public trust admission. P3's causal emission is structurally disabled until a separate authentic manifest/engine/source adapter is proven and authorized.

Formally, for moment (m) with available legacy information (O_m), the compiler (C(O_m)) returns an admissible set (A_m) of sentences with traceable supporting atom IDs and authority ceiling. The static selector (f_θ(A_m)⊆ A_m) can change *which* admitted claims are uttered; it has **no operation** that extends (A_m). For zero-selection hallucination, require (\mathrm{Claims}(f_θ(A_m))\subseteq A_m). This containment is a coding invariant, not an original theorem, and it does not imply the admitted original facts themselves are globally true.
