# C3X 0.30 R29 — Learner transfer pilot

## What to hand to a player

Use the [participant ZIP](https://drive.google.com/file/d/1bn0dGxCsZCNTEou8t2VwIaHwbzyGeoXc/view).
Give each person a single assigned lesson file and the same assessment.
Record their first choice for the lesson position before revealing the
lesson. Ask them to close the lesson before opening the assessment.
Each item asks for the threatened bishop square and a legal pawn move
that preserves the stated plan, or an explicit no-solution answer.

| Arm | Material |
| --- | --- |
| A | Stockfish evaluation and the public principal variation, plus the same separately obtained alternative line |
| B | A plus the board explanation of the c5 bishop threat and …a4/b4 |
| C | B verbatim plus the evidence from the actual native cutoff and the bounded replay |

C describes an effect on the source path and a stable recommendation.
It has one additional short panel. A measured C−B effect would apply
to access to that panel as presented, which adds reading material.
Any later test that attributes efficacy specifically to factual
provenance should add a length-matched control.

## Scoring and interpretation

The pilot packet has two altered continuations from the teaching game
and four previously generated positions from other games. For transfer the
primary response is correct threat and correct conditional plan together.
Keep each component and missingness separately. Accept any legal straight
pawn advance that permits the tested capture and legal recapture. In one
item a different pawn than the one originally specified makes the plan
work, so the current transfer bank has three positive and one negative
items. Keep this pilot distribution explicit.

The synthetic answer set passed all six items. No people have taken
the assessment in this increment. The pilot can reveal confusion about
rules, timing, or interface; an effect estimate needs a separate sample
of participants with a new and more balanced item bank. Balance assignment
by prior playing ability, assign each learner one arm, and keep answer keys
outside the participant package. Separate same-game scores from new-game
scores and document treatment of incomplete answers before collecting them.

The primary comparison for the research question is C−B on the new-game
joint endpoint. B−A measures the contribution of the board reasoning
package. An additional advice-choice test can use the R28 appropriate
reliance denominators and independently corroborated weak advice. Report
final move quality, agreement with Stockfish and willingness to switch
as distinct outcomes. A prediction gain without a transfer gain would
support the source trace as a verification feature.
