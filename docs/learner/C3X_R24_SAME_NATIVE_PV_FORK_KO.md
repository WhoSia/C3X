# Qxe2 이후의 서로 다른 두 수순

시작 FEN `r3k2r/ppqn1p2/2pbpp2/2P4p/3P3N/7P/PP2bPP1/R1BQ1RK1 w kq - 0 13`

두 실행의 추천 수는 **Qxe2**, 표시 평가는 **+89cp**였어.

| Stockfish 관측 | GUI에 보고한 주요 수순 | 내부값 |
| --- | --- | ---: |
| 깊이 12 | `13. Qxe2 Bh2+ 14. Kh1 Bf4 15. b4 Bxc1 16. Rfxc1 Qf4 17. Nf3 a6 18. Rc3` | 292 |
| 깊이 18 | `13. Qxe2 Be7 14. b4 f5 15. Nf3 Nf6 16. a4 Ne4 17. b5 Bf6 18. Ra3 Rb8` | 292 |

2번째 반수에서 흑 수가 **Bh2+ / Be7**로 갈렸어.
…Bh2+는 체크를 걸어 백에게 즉시 대응을 요구해. …Be7 뒤에는 백이 체크 상태에 놓이지 않아.
고정 깊이와 노드 제한으로 분리한 재실행에서 4/4회 재현했어.

같은 분기점에서 두 수를 각각 고정한 Berserk 평가도 비교했어. 점수는 흑 기준이야.

| 분기 수 | 깊이 12 | 깊이 14 |
| --- | ---: | ---: |
| Bh2+ | -111cp | -109cp |
| Be7 | -95cp | -98cp |

표시 점수는 추천 수와 함께 나온 값이야. 여기서 달라진 건 엔진이 보여 준 후속 수순이야.
