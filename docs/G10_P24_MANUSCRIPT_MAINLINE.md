# C3X G10-P24 — Manuscript + Experiment Mainline

## Scientific thesis

P23 established a clean separation: executable intervention support can be acquired prospectively without outcome leakage, yet the frozen P22 activation field still failed on the support-sealed population.

P24 asks a stricter question:

> Can activation transport be restored by a low-dimensional engine/ecology calibration layer that never sees source identity, and does that calibration transfer to new source identities after coefficients are sealed?

This is not a rescue of the P23 verdict. P23 remains CLOSED/FAIL.

## Why P24 is scientifically distinct

P23 ruled out a support-only explanation. The dominant post-primary structure was:

- predicted ACTIVE rate 0.36 vs observed activation rate 0.20;
- large source/ecology variation;
- Stockfish 19 and Ethereal substantially stronger than Berserk;
- no MOVE_ORDER/CUTOFF family rescue.

P24 therefore promotes **regime calibration transport** to the next scientific object.

The object sequence is now:

```
world availability
→ pair activity
→ executable intervention support R
→ parent-class activation A
→ ecology/engine calibration transport C
→ local Q0 fiber authority
```

## Anti-memorization principle

The calibration layer may never receive source/event identity.

Allowed descriptors are semantic and reusable on a new event:

- engine identity;
- time-control class;
- field-structure class;
- frozen P22 R1 prediction;
- frozen BASE-only feature block.

Forbidden:

- source_id / tournament name / broadcast id;
- event-specific one-hot or source-specific intercept;
- player identity;
- post-intervention outputs;
- Q0 outcomes.

A model that succeeds only by remembering Prague/Biel/Saint Louis is not ecology transport.

## Two fresh cohorts

### Calibration cohort

One fresh presealed source in each ecology cell:

1. classical closed/round-robin;
2. classical open/Swiss;
3. rapid open/round-robin.

After both cohorts are frozen and independently pass executable-support quotas, calibration-cohort FULL_CLASS outcomes may open.

### Locked transfer cohort

A disjoint source identity in each same ecology cell.

Its FULL_CLASS outcomes remain sealed until:

- calibration candidate is selected;
- coefficients are frozen;
- classification threshold is frozen;
- model artifact hash is recorded.

The transfer cohort is the only authority-bearing P24 primary test.

## Candidate calibration family

All candidates retain the frozen P22 R1 signal.

- **C0_GLOBAL** — R1 only.
- **C1_ENGINE** — R1 + engine.
- **C2_ECOLOGY** — R1 + time-control + field structure.
- **C3_ENGINE_ECOLOGY** — R1 + engine + time-control + field structure.

No source-specific term exists.

Selection is calibration-cohort only. Leave-one-source-out log loss is primary; balanced accuracy is secondary. The lowest-complexity model within 0.01 mean log loss of the best candidate wins. Threshold is chosen only from a frozen finite grid and sealed before transfer outcomes.

## Primary transfer endpoints

P24 PASS requires:

- transfer log loss better than uncalibrated R1;
- transfer Brier score better than uncalibrated R1;
- balanced accuracy >= 0.70;
- positive recall >= 0.50;
- negative specificity >= 0.70;
- BA >= 0.60 in at least two transfer sources containing both classes.

A calibration improvement without discrimination/cross-source robustness is PARTIAL_PASS, not PASS.

## Paper contribution stack

### Contribution 1 — executable-support separation

P23: support can be prospectively sealed before activation outcomes, and adequate support does not guarantee activation transport.

### Contribution 2 — source-memorization-resistant calibration test

P24: calibration is permitted only through descriptors that survive source replacement, then tested on source-disjoint matched ecologies.

### Contribution 3 — authority propagation

The same state machine governs the deployed explanation path. Product code may abstain when calibration scope is unverified, but implementation success cannot promote Track-A authority.

### Contribution 4 — negative-result value

If P24 fails, the paper has an unusually clean failure ladder:

```
support insufficiency (P22)
→ support repaired (P23)
→ frozen activation field still fails (P23)
→ prospective low-dimensional calibration attempted (P24)
→ [pass or persistent regime instability]
```

## Relation to prior work

Transportability, positivity/support, calibration under dataset shift, domain adaptation, and causal interpretability are donor literatures, not novelty claims.

The narrow C3X contribution is the coupled design:

1. executable intervention support is outcome-blind and prospectively sealed;
2. mechanistic activation is evaluated only on executable worlds;
3. calibration cannot memorize source identity;
4. calibration is frozen before a source-disjoint transfer cohort opens;
5. the same authority state is enforced in the explanation product.

## Identification assumptions to disclose explicitly

- engine binaries/protocols are stable within each frozen run;
- R=1 defines an experimental target population, not all chess positions;
- ecology descriptors are coarse and may not block every source-specific difference;
- source-disjoint transfer tests descriptor transfer, not universal transport;
- FULL_CLASS activation is an operational engine-mechanism endpoint, not human cognition;
- Q0 authority remains downstream and cannot re-enter without prospective parent-class authority.

## Claim ceiling

Do not claim:

- universal chess mechanism laws;
- source-invariant causal transport unless the locked transfer cohort passes;
- population representativeness outside R=1;
- human strategic intent;
- causal evidence from Track-B CI, UX, or fluent commentary;
- novelty for generic calibration/domain adaptation/transportability.
