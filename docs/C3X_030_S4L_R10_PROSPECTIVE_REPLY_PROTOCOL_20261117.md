# C3X 0.30 S4-L/R10 — Prospective replay of PV versus sampled replies

2026-11-17 KST. This is a prospective evaluation protocol for a new exploratory cohort, not an opening of any earlier sealed cohort. It tests tactical/strategic evaluation transport from Stockfish to Berserk. It does not test whether an R9 internal intervention generalizes.

Use the official TCEC Season 29 Division P archive (`master-archive/TCEC_Season_29_-_Division_P.pgn` at `3dd69a40b3cf6ccc74144df7411ef4e8e2140286`, SHA-256 `b417f739dc4adfbbe2c65779336f3da5ab515e999dca1ad1a0c785b3980521c8`). It is a different event from the logged S29 Superfinal development cohort. Earlier sealed inputs stay closed; no global cross-event opening-disjointness claim. Sort rounds numerically as main round and board. Use one position per game and skip a game when its exact first 12 ply already occurs in an admitted game. Select the first eligible position among plies 24, 32, 40 for each game. Keep the first eight eligible games and accept a smaller cohort if the source is exhausted. Exclude nonstandard starts, incomplete/invalid histories, and repeated positions. The existing C3X R4 Stockfish 16 build (SHA-256 `3766b594a274e83bda1b2b1a8f67747b2f26724e6a64e388e659fb00c1fd12cb`) with no experimental control files, classical, 1 thread, 16 MiB, independent position resets. Nominate the top two candidates from a 48k-node MultiPV=2 scan. For inclusion both scores must be ordinary non-bound centipawns with distinct legal roots and absolute gap at most 30 cp. Candidate selection ignores PGN outcomes and annotations. Preserve source hashes and cohort before judge runs.

Prediction for each candidate after playing it, from original mover POV:
- PV baseline: free opponent search, 48k requested nodes.
- Reply tree: 24k-node MultiPV=3 opponent reply discovery, then new searches at 8k requested nodes after each of those three replies, with the original history preserved. Use minimum mover score and its reply. Count discovery toward total budget.

Judge with independent Berserk 14, fixed depth 12 after every legal opponent reply, new game per call. Target is the minimum finite unbounded judge score after each candidate; record a terminal draw as 0 and abstain on mate-valued leaves or if any reply is missing/ineligible. Evaluate candidate ranking sign including ties and absolute candidate-gap error. Also measure exact minimizing-reply set membership for each arm, with ties acknowledged. Report nodes by arm, requested versus reported. Retain direction, calibration and reply-hit results even if they disagree. No claim beyond the sampled games. If fresh source custody or input eligibility fails, record the actual limitation without silently relabeling earlier evidence.
