## Negative-lineage logic: pruned branches lack child returns
C3X 0.24 existing native source-to-child and ancestor instrumentation was reread:
- `tools/c3x_024_P2_passive_native_descendant_lineage_overlay.py`
- `tools/c3x_024_P2_R2_passive_ancestor_root_value_overlay.py`
- `harness/c3x_024_P2_R2_actual_ancestor_root_survival_court.py`
Old C3b explicitly classifies `ACTUAL_CONTINUE` as `C2_ACTUAL_CONTINUE` with **no child entry, no child return, and no ancestor-value chain**. It would be a category mistake to demand a returned child score from a candidate that was excluded by a pruning guard. The old T4 source observer recognizes `quiet_prune` and `qsearch_prune` only; it does NOT directly instrument `capture_prune`. It cannot simply be claimed as successfully applied to the new game14 capture case without a new explicitly source-exact patch and a replay audit.

Therefore a faithful full-mediation experiment for game14 must certify *exclusion*: original SEE false; the C++ `capture_prune` guard actually took continue at that exact observed node; the candidate was not searched; a second source-exact intervention changes only the truth value of that ONE guard while holding TT-FIRST treatment and run settings fixed; the counterfactual child is then visited (or not) and changes later root candidate ranking (or not). This is an **exposed hypothesis** after observing game14 and is NOT a prospectively confirmed explanation. A potential falsifier: re-enabling only the selected guard leaves bestmove f3f4 or source event no longer matches. One must separately rule out broader TT pathways and avoid equating an effect on root preference with concept-level human explanation.

## Manuscript Results (rewritten)
A first-reader intervention on a newly sampled sixteen-game cohort reached its intended Stockfish transposition-table source on every trial, but only one trial changed the root move. The changed choice was not accompanied by a source-identical SEE invocation common to both executions after the reader event. This could mean that the intervention bypassed SEE, or that it made a new SEE test reachable. We went back to the original engine source rather than deciding between these alternatives from the absence of a common call.

The new source-chronology audit resolved one part of the ambiguity. In the changed game, the untreated execution reported two qsearch-pruning tests, both returning false. The intervention execution reported those same two tests and a third, capture-pruning test that also returned false. That third call occurred after the physical reader suppression and was not present in the uncensored untreated witness prefix. At the direct C++ caller, a false return satisfies the condition to skip the candidate. In another new game, two extra post-reader SEE calls were likewise observed without any root-choice change. Their existence is therefore not by itself an explanatory mediator.

The distinction suggests an asymmetry in the evidence required for pruning-based explanations. A branch that was actually skipped has no descendant evaluation to propagate to the root; an ordinary value-return chain cannot certify the effect of a child that was never searched. A testable mechanism instead compares the factual exclusion with a counterfactual source-local re-enabling of that same guarded candidate. The game in which a root flip and a new capture-pruning event coincide now provides a sharply delimited negative-or-positive test for this mechanism. It does not yet establish why Stockfish changed its final move, nor does it demonstrate a generalizable, human-useful explanatory concept.
