# C3X 0.30 R32 — A window-dependent early return changes Rb2 into g5

On the exposed R29-031 fixture, the R31 scout-hint mask preserved
the 1947 return of the entire Kg7 scout. Inside that scout, Bc6
returned 1947 in the ordinary run and 1894 in the masked run.
The black-to-move node after Bc6 then retained Rc1 as its TT move.
The actual near-term cache writer was the main search at ply 2.

| Scout arm | Bc6 scout depth | Bc6 scout return from White's perspective | Stored depth at Bc6 PV entry | Raw value stored for Black |
| --- | ---: | ---: | ---: | ---: |
| Ordinary | 12 | 1947 | 12 | −1947 |
| Bc6 hint masked at Kg7 | 9 | 1894 | 9 | −1894 |

Both resident entries had a lower bound, Rc1, the same PV and generation
flags and static evaluation −1897. Both first Bc6 PV calls entered at
depth 11, with the same window and the same key and slot. The ordinary
Bc6 PV return was 1827, followed by a Kg7 PV return of 1934. The masked
Bc6 PV return was 1952 and immediately crossed the Kg7 PV threshold.
Old and observational builds agreed with the R31 receipts.

## What changed the final move

The Bc6 TT value contributes to the singular verification threshold
for Rc1. The verification temporarily excludes Rc1 and searches other
black moves. Restoring the ordinary TT value at the ply-2 consumer in
the masked world moved the threshold from −1908 to −1961 and restored
g5 at the root. Moving just that threshold also restored g5. In both
runs, singular verification still returned −1988, the engine still
extended Rc1 by one ply, and Bc6 and Kg7 both returned 1952. Swapping
the resident depth alone in either direction did not change those
endpoints. In the ordinary world, the reverse value and threshold
changes preserved g5 and changed the Kg7 PV return from 1934 to 1912.

Inside the Rc1-excluded test, Stockfish examined the nested 42…g5
after 41…Kg7 42.Bc6. Switching only the depth-3 g5 child to beta
1962 reproduced the final g5. Restoring its beta to 1909 while keeping
the changed enclosing threshold restored Rb2. The final move in all
of these comparisons comes from the actual 41st-move competition.

| Nested 42…g5 search in the masked world | Local return for White | Searched 43.b5 | Final 41st move |
| --- | ---: | --- | --- |
| Native beta 1909 | 2140 | No | Rb2 |
| Beta 1962 only at the nested g5 call | 2104 | Yes | g5 |
| Changed outer threshold with this call restored to beta 1909 | 2140 | No | Rb2 |
| Beta 1909, suppress child futility | 2128 | No | Rb2 |
| Beta 1909, suppress child futility and null-move entry | 2104 | Yes | g5 |
| Beta 1962, force child futility | 2140 | No | Rb2 |
| Beta 1962, force null-move entry | 2128 | No | Rb2 |

At 1909, the calculated futility floor equaled beta. The first early
return used the evaluation 2140. When that exit was suppressed, the
next null-move test cut off at 2128. At beta 1962, ordinary futility
failed and the null-move admission threshold was 2148, above the static
evaluation 2140. The engine then tried b5, reached the needed threshold,
and updated the main-history entry for that pawn move from −4548 to
−3796. The early returns omitted this work. The gate-only interventions
link this difference to the final recommendation. The relative causal
contributions of the history update, TT writes and the rest of the
extra search remain open.

With only the changed nested g5 window, the first changed later root
candidate at a common alpha was Ke5. It formerly took the lead with
−1928 against −1951. It then returned −1951 at the same threshold and
failed to take the lead. The later Rb2 and g5 searches continued from
the changed competition. Their individual values can have different
windows. The work shows how to explain a different winner even when
the intervened subtree returns the same move score to the root.

## Scope

This isolates one active route in the masked, single-threaded
32,000-node world. The ordinary and masked Bc6 PV returns differ
independently. An extension-only intervention in the ordinary world
moved Bc6 from 1827 to 1903 and changed the final move to Ke5. The
reverse extension change in the masked world moved Bc6 to 1969 while
leaving the Kg7 cutoff in place. These extension experiments remain
separate from the threshold-only mechanism. This fixture was already
examined by R31. Next fix the event-selection rule for fresh games and
include positions where the gates differ yet the root move is invariant.

The R31 Nd7/a4 learner comparison remains available with the same
