## Accepted question, not a promised result

Then test separately whether the same explanation has independently validated **conditional future-reply content** and measurable **human comprehension value**.

No NNUE feature label, public PV, scalar evaluation or generic transposition-table count is presumed causally sufficient. Source-side total effects and strategy values are different evidence channels.
