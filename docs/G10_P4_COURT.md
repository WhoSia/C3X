# C3X G10-P4 — Evidence Promotion Calculus

P4 turns P3's typed invariant architecture into an executable authority-governance kernel.

## Distinction from existing chess explanation

Natural-language commentary, Stockfish grounding, move classification, concept extraction, factual verification, legality checking and trace logging all have public precedents. P4 does not claim novelty for those capabilities.

The P4 novelty target is narrower and stronger: **an executable contract mapping typed evidence obligations to permitted explanation authority, with explicit promotion debt and composition/transport blockers.**

## Core transitions

- MEASUREMENT_ROUTING → CHESS_NATIVE_SURFACE
- CHESS_NATIVE_SURFACE → MECHANISM_CANDIDATE
- MECHANISM_CANDIDATE → LOCAL_CAUSAL_EXPLANATION
- multiple LOCAL_CAUSAL_EXPLANATION certificates → COMPOSITION_CANDIDATE
- COMPOSITION_CANDIDATE → TRANSPORTABLE_CAUSAL_PATTERN only with new prospective held-out transport evidence

## Safety against authority laundering

Repeated engine agreement, legal root-choice change, intervention response, factual correctness, and fluent commentary cannot independently authorize causal language.

A failed promotion produces a machine-readable debt object, not an implicit fallback.
