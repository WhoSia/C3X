# C3X 0.27 — A Prospectively Frozen TT Source Intervention Does Not Yet Identify the SEE Mediator
2026-10-20 · Original licensed September chess corpus · RESEARCH MEMO 03 (bounded experiment plus source audit; paper novelty still HOLD)

## Abstract
An engine's reported principal variation is a product of interacting internal computations. Demonstrating an intervention on a transposition-table (TT) reader changes a chess move is a causal claim about that reader; demonstrating SEE subsequently evaluated a position is not necessarily a causal claim about static-exchange evaluation as a mediator. We prospectively selected 16 source-game-disjoint positions from September 2026 Lichess broadcasts without running an engine, froze both the cohort and 16-game intervention protocol in Git, and then ran the earlier C3X Stockfish16 physical writer/reader instrument unchanged. All 15 games with a preselected first TT reader pair exhibited the intended physical block, while the sixteenth was an ineligible hold. One of the 15 changed its final root move (from b3a4 to f3f4). A passive SEE observation initially identified three one-sided event signatures across two games. After restoring the original full-state SEE observer in a separate retrospective audit, we found 58 SEE events with matching native ancestry, search depth, alpha-beta window, and original Boolean after matched TT source-use/block across four games; none of those four games changed the root move. In the changed game, the two shared SEE events occurred before the selected TT source contact, while a third event appeared only in the treated observation. The result is a real source-intervention/root-outcome contrast with a still-unproved SEE mediator. The observation cap prevented global claims about event absence in eight games.

The physical TT-FIRST reader suppression was executed cold and duplicated for each eligible game, with writer-reader key, slot, epoch and root-call provenance verified. The complete run 39370521779 finished with 15 of 15 eligible physical first-reader contacts and one root bestmove change among 15 intervened games. The 16th game (ID 10) lacked the preregistered STRICT pair and remained NO_ELIGIBLE_SOURCE_PAIR_HOLD; it was not silently substituted by an easier alternative.

The changed game was ID 14, source-game SHA256 0822ec4ddab0339d51a65f3a9d077a1245b2402b111e78a3aa90d2a4d9a83652, starting from original root FEN4 r1r3k1/p3pp1p/3p2p1/3Pb3/1p6/1B1R1PP1/PPP4P/1K2R3 w - - . The baseline engine selected b3a4, while the physically blocked FIRST reader arm selected f3f4. Source actually played f3f4 in the historical score; agreement with the human move is not an engine-strength validation.

There was no SEE return-value intervention. Native SEE witness matching in the bounded first32 event prefix indicated two treated-only events in game 7 without a root move change, and one treated-only event in changed game 14. Eight games hit the native first32 source-observation limit; unobserved events cannot be treated as absent.

## 4. Retrospective full computational-state recheck
The first prospective engine job included the earlier SEE path observer but not every T1 search-state field, so it could not run a complete T1 match for four eligible cases. This gap was repaired in a separate run using the original 0.23 T1 `native_full_search_state_overlay`, the exact frozen source and physical target inputs, and no change to SEE logic. The first retrospective job completed calculations but failed at artifact packaging due to an output-name bug; final rerun 39371068226 passed and produced a result SHA256 44efdc93cf7d5c3e7f840c025ae064718688c1023676cefe1ba2d61191b46946.

This replay identified 58 native SEE occurrences with matched ancestry and full call computation state AFTER the original selected TT value use and corresponding treated TT physical block, across games 1 (7 events), 2 (18), 5 (17) and 7 (16). Every one of these games preserved its final root move. Conversely, the sole changed game 14 had two SEE signatures common to both runs before the selected TT reader source event and one treated-only observed event. A common, fully source-state matched downstream SEE event capable of linking the changed move back to the source intervention was not established in that game. There is no evidence here that the added SEE Boolean mediated root choice; the exact decision to prune or pass at its source guard was not independently observed as a consumer witness.

## 5. What this shows and what it does not
There are three different statements: (a) physical TT reader suppression changed the root result (supported for game14), (b) native SEE source events differ somewhere in the two runs (observed in bounded prefixes of games7,14), and (c) a specific intervened TT reader changed root selection **through** a particular SEE guard outcome (not established). A signal shared across all three reports does not supply the missing causal counterfactual. We must avoid measuring only those games that changed root, conflating source-time ordering with logical necessity, or inferring global SEE event absence from an observation cap.

The new experiment is a real prospective replication of a source-intervention protocol on game-disjoint data, and the full-state recheck supplies testable constraints on a subsequent mediation claim. It does not establish a strategic advantage of the selected root move, original engine intent, human learning benefit, or general causal mediator identification. The prior C3X source-program failures (0.19 K4, 0.24 prospective prediction and 0.25 M6 rare root flip) remain part of the honest historical record.
