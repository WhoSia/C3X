## Precise interpretation: what is a causal result?
The local root-choice difference is a real matched two-world source intervention result with identical root game, pinned engine, source selector, cold duplicates and verified physical contact. The native TT FIRST reader suppression is sufficient to change the final root move in one of these 16 cases. This does NOT identify a natural SEE mediator. Source SEE chronology is a *necessary observational audit*, not sufficient to prove that its Boolean was used in a pruning return, parent value assignment, or final root-choice update. The actual original engine's source T4 prune/continue observer is reusable for more precise guarded consumer traces, but T4 full source event metadata would require another prospectively frozen targeted run.

## Manuscript Results — native interventions without a common SEE path
The operator-level question became testable on a new cohort only after the source games, untreated engine outputs and physical reader targets had been independently frozen. We selected 16 previously unused broadcast games, rebuilt the original Stockfish16 source instruments and duplicated every cold run before applying the preregistered first-reader suppression. All 16 treatments made physical contact with the intended transposition-table reader, but only one changed the final root move. The event occurred in a game whose O-order baseline preferred b3a4; suppressing the first chosen reader produced f3f4, the move chosen under the separately frozen F-order baseline. The historical cross-order restoration heuristic, however, correctly predicted only ten of sixteen treated best moves; simply predicting no change was correct in fifteen.

The source trace gives a more restrictive answer than the final-move comparison. Four games contained identical native SEE calls in both worlds after the relevant TT source event, yet none of those four changed its final move. In the one game that did change, no such common post-source SEE identity appeared in the uncensored observed prefix; the two executions instead contained different small sets of observed SEE calls. This is not proof that SEE was irrelevant. An asymmetric call could become active only in one search world, and a TT reader can also affect the root by a different pathway. What the experiment rules out is the shortcut from 'we saw a source-matched SEE call' to 'that call mediated the changed chess decision.' The missing evidence is a source-level consuming guard and a subsequent parent/root value-assignment lineage under matched computation states.

New result is a prospective game-disjoint operator study preserving physical contact and bounded SEE observability; this is more substantively testable than prior purely post-outcome development source contacts. But N16, 1 flip, first32 SEE prefix and incomplete actual consumer chain are insufficient for a general natural mediation theorem.
