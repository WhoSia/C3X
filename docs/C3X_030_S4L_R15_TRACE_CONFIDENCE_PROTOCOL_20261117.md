# C3X 0.30 S4-L/R15 — Root-switch confidence follow-up

Exploratory follow-up specified after observing R14 source trace coverage and before running either reference depth. This reuses the same eight unresolved League 1 questions and the exact same source searches. Its outcome is forecast uncertainty for candidate rank, not a new directional predictor.

All arms use the R14 public-tree rank as their most probable class. The constant rule assigns probability 0.75 to the predicted class and 0.125 to each other class, including tie. The public-warning rule moves to 0.625 with a 0.1875 mass on each other class when either branch ends in an ordinary bound or has a PV-first-move change across its latest two distinct ordinary unbounded public depths. The trace-warning arm uses the same public warning plus an additional downgrade when either branch's latest observed root iteration has two distinct PV-updating moves inside one root invocation. A new root ID (for example aspiration retry) alone cannot trigger it. Require complete logs and preserve abstentions. The probability levels are fixed heuristics, with no fitting.

Primary comparison is mean three-class Brier loss (sum over classes divided by the number of shared judged questions) against Berserk depth 16. Depth 18 is sensitivity. Report the difference versus both constant and same-public-warning controls, the number of adjusted questions, and the scope of this exploratory search-process signal. The policy is frozen before judging but was designed after observing the first policy's lack of source coverage. An event-disjoint replication is necessary before using it as a calibration rule.
