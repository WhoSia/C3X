# C3X 0.30/P6 — Structured, Source-Replayed Chess Commentary Without Invented Explanations

**Research day 2026-11-11 KST**. The C3X initial question [C3X 1.md, original Drive](https://drive.google.com/file/d/1zbNnM9shiG-IU-oFCbgB3Z5oMeKlZyNf/view) asked for an educator's account of why Stockfish mildly prefers one move over another. P3/P4 already produced actual search plans. P6 makes those *actual chess continuations readable in Korean*, with every asserted move replayed, preserving source provenance and respecting the distinction between a verified path and an inference about why an engine internally chose it.

## 4. Research contribution and critical limits

This P6 stage is primarily **engineering reproducibility and a sourced pedagogical interface**, not evidence that the true original engine's decision was *caused* by the articulated path. Four critical things remain distinct:

| Layer | Validated in P6 | Unvalidated |
|---|---|---|
| Chess rule facts | Every move legal, SAN matching original FEN, unique full 5-ply source path | Whether opponent actually chooses that branch |
| Search provenance | Original Source-Stockfish policy's explicitly calculated candidate continuation | Whether root decision's internal search relied on this particular continuation |
| Presentation fidelity | Korean clause accurately reproduces tested source UCI/SAN moves, no extra unsupported causal claims | Fluent strategical explanation of why branch maintains advantage |
| Independent educational validity | Previous P4-B used Berserk on **exact archived** eight source paths, separate from dynamic UI | All-opponent-reply minimax, independently judged arbitrary FEN, Chess.com blind learner improvement |

**Next P7 candidate**: a truly separate performance-controlled *annotation-layer* architecture with trained-model optional realization and claim-level validation; same-source evidence must still bind each sentence, and a second-source engine or actual causal search instrumentation is needed to promote branch evaluation claims. Another attractive source-backed control is Martin's original mirror metamorphic audit already implemented at P5, which can be shown alongside the source explanation as a graded *finite-depth gap instability* warning. Jacovi faithfulness remains separate from content accuracy.
