## Mathematical oracle and falsifier

An interval guaranteed-winner rule is sound only with candidate-comparable sound exact score envelopes. For ordered root candidates, earlier ties win: w is certain iff Lw > Uj for all earlier j and Lw >= Uj for all later j. Previous local complete oracle: 216 3-candidate interval assignments, 2500 2-ply minimax leaf interventions. No native Stockfish implications without valid score-envelope assumptions.

Additional independent finite counterexample in tools/c3x_028_bound_value_counterexample.py: candidate A <= 2 and B >= 1 admits both A and B as winners, among 40 jointly feasible bounded integer assignments.
