## Exact native dynamics

For fixed bonus, f(h+1)-f(h) is 0 or 1; hence monotone and nonexpansive in the integer domain. This holds only with a common bonus and same coordinate, not across different search decisions. Smooth relaxation h'= (1-|b|/D)h+b gives contraction of differences. With scaled cumulative update exposure tau=sum |b|/D, constant sign and small increments, dh/dtau=D sign(b)-h; not physical time, not exact engine ODE. Changing search path changes b and the selected coordinate. Root choice is a finite-horizon output, not a thermodynamic equilibrium.

## Product model
For initial move a, common horizon H and fixed opponent/own policies, q_a(s) is probability of reaching independently adjudicated good set before bad set; for unresolved terminal states retain interval [0,1]. For binary terminal success use lower and upper Bellman recursions; opponent worst-case uses min not expectation. Add pair contrasts q_a-q_b and intervals [L_a-U_b,U_a-L_b]; never derive probabilities from scores by arbitrary softmax. Unit-test toy examples (not native performance), then evaluate on frozen near-equal real positions. Native source causality and plan robustness remain distinct.
