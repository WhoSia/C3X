# C3X 0.30 R29 — Source evidence, chess merit, and transfer

| Question | Evidentiary unit |
| --- | --- |
| Why did this Stockfish run choose its move? | Identify the original root producer, the named alternative, its relevant window and whether the observed computation was a full search or a bound. An intervention needs matched entry fields, controls and an endpoint. |
| Why should a player prefer it? | Show a legal alternative, the adversary's response and the resulting position. Use named independent reference conditions. If the reference or the source disagrees, expose the disagreement. |
| What can a player learn from the explanation? | A matched arm comparison whose new-game question requires both identifying the threat and carrying out a strategy through the opponent's reply. |

The [single-case intervention](C3X_030_R29_ND7_A4_RESULTS_20261121.md)
shows that withholding the tested b4 hint was insufficient to change
the final native choice. Independent board evidence supports b4 as
an effective defense under the recorded reference regime.
The [new-game campaign](C3X_030_R29_UNSEEN_RESULTS_20261121.md) provides
positive local interventions for two close games, while showing that the
selection rule abstains on both reference depth reversals. Use those
positive and negative examples when describing the evidence to learners.

Development decision: maintain separate dispatch for cases where a
source read matches the chess reply, where only a bound explains the
source comparison, and where the rule cannot pick an event. The next
source campaign should preregister a fallback derived from the actual
foil search after the first rule abstains. It should use another PGN
issue and preserve the first-rule exclusion count, so extra coverage has
a clear denominator.

For the actual [pilot](C3X_030_R29_LEARNER_PILOT_20261121.md), keep the
board prose matched in B and C, and first observe whether players can
use it on other positions. Cui, Ling and Ng offer a strategy-teaching
protocol that tests opponent moves outside the principal variation.
Press and Golubev supply prior work on contrastive chess explanations
and reference-based evaluation. The project-specific contrast is whether
adding verified provenance of this actual engine search helps a person
generalize or judge the advice.
