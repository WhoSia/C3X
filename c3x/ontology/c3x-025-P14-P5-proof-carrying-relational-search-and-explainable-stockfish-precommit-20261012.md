## The mathematical object and missing soundness bridge
Fix one chess root position, original Stockfish source revision, legal root moves A, a precise scoring/evaluation semantics and deterministic tie rule, entire search budget and controlled execution policy. Let H be *all admissible complete hidden search-machine states* compatible with partial observation o, including TT entry contents, replacement generation, rule50/repetition, search stack and ordering plus relevant clocks if budget permits. Let E_u(h) be the complete execution of engine policy u. The genuine reachable set of policy-indexed complete execution/world outputs is `K*(o) = {E_u(h): h in H, u in U}`. Define candidate utility vector ONLY if its score meaning is consistent across ALL compared moves/policies; original `RootMove.score` and a fail-soft aspiration estimate do not supply these comparable exact utilities. A policy-independent true root candidate-value vector may instead need separately defined finite-search minimax or rule-correct evaluation semantics; executing alpha-beta with changing aspiration windows does not magically materialize it.

A sound overapproximation `K#` must contain every **actual** world in `K*`, with an explicit source-to-constraint proof. Adding empirically observed inequality without justification can *exclude hidden worlds and make a false proof*. A proof-carrying explanation must cite which original source transition/rule justifies each admitted relational inequality; otherwise emit `ABSTAIN` and maintain original policy. Finite trace observational equivalence does not identify hidden counterfactual outputs. Full K* is finite/computable in principle for a precisely finite and bounded discrete machine with a fixed bounded search, but far too large; unrestricted arbitrary machine control and budget are not a tractable full K. This is a TCS abstraction/verification problem, not a SHAs-and-audit project.

## Executable theorem prototype: difference bounds and closure
For toy integer comparable utilities `v_i`, admit only **proved** difference rules `v_j-v_i<=c`. Floyd-Warshall closure on the weighted difference constraint graph yields derived inequalities and detects inconsistent negative cycles. A robust strict winner w can be certified if closure establishes for all rivals j: `v_j-v_w<=-1` (integer scores; more generally strict negative bound for real scores). A chain `v_B-v_A<=-1`, `v_C-v_B<=-1` certifies A above both, even if the independently projected candidate marginal intervals overlap. Constraints from mere execution logs carry `TRACE_ONLY` and are rejected, not fed to the graph. Enumerate EVERY toy joint score world [0,3]^3 and EVERY difference-rule system with ≤2 rules over 42 directed labeled options, compare graph closure and actual worlds to reject false certificates. This is a theorem experiment for the fragment, NOT an original SF16 soundness certificate.
