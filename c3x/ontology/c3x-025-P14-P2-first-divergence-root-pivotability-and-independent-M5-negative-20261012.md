## 2. Correct mathematical theory

Let the fully specified policy-indexed deterministic search machine have initial state `s`, policy `u`, executed trace `τ_u(s)`, recorded actual q-parent projection `Q_u(s)`, final original-root candidate observation `C_u(s)`, final move `F_u(s)`, and node count `N_u(s)`. The Sicilian supplies a source-specific witness that `Q_SHAM(s) != Q_SCORE(s)` and `N_SHAM(s) != N_SCORE(s)`, while `C_SHAM(s) = C_SCORE(s)` for the recorded final fields and `F_SHAM(s)=F_SCORE(s)`. **Policies differ**, so this is not a proof that a fixed-policy `F_u` fails to factor through board-state projection. Distinguish within-policy fiber factorization from intervention-uniform state projections. Earlier Cousot–Cousot / Sangiorgi / Geiger causal abstraction prior art remains canonical in the shared Research OS.

**Proposition A (nonidentifiability of transient root-mediator effect from sampled events and final fields):** Given observations `(Q_u,C_u,F_u,N_u)` for both policies `u∈{0,1}`, there can be two deterministic latent programs producing **identical entire measured observations** under both policies, one in which an unreported intermediate candidate score is invariant under policy, another in which it differs transiently and is restored before the final root endpoint. Thus the policy-induced transient candidate effect is **not identifiable** from only these measurements. Proof by construction: [C++ finite executable countermodels](../../tools/c3x_025_P14_P2_pivotability_identifiability_rank_court.cpp), check two indistinguishable causal mechanisms with different intermediate candidate mediation. This elementary counterexample is a C3X measurement-boundary result, **not a novel general causal-identifiability theorem**. No claim the original Stockfish selected candidate was actually transiently altered.

**Proposition B (strict exact-score margin certificate, conditional):** Let finite root-candidate set `A` be the same in both runs and fully comparable **exact** scores `s_u(a)`, `s_v(a)` exist for all `a∈A`. Suppose original winner `w` is unique with strict margin `γ = s_u(w) - max_{a != w}s_u(a) > 0`, and every candidate's policy-induced drift has certified supremum bound `|s_v(a)-s_u(a)| <= ε`. If **`γ > 2ε`**, then `w` is also the unique winner under policy `v`, because `s_v(w)-s_v(a) >= γ-2ε > 0`. This is an elementary sufficient bound, not a new chess-engine theorem. Exact C++17 finite exhaustive regression tested **15,625** score-vector pairs over three candidates with scores in 0..4, 261 pairs satisfying the sufficient strict-margin certificate (all preserve winner), and 7,500 rank-changing pairs outside the certificate, plus deterministic compensating-mediator counterexamples. [Real GitHub Actions theory + independent M5 audit SUCCESS #38194744739](https://github.com/WhoSia/C3X/actions/runs/38194744739).

**Crucial scope:** Actual SF16 `rootMoves` may contain `-VALUE_INFINITE` sentinels and alpha–beta bounds, not uniformly exact comparable scores. We have NOT certified sound `ε`, candidate-set invariance or strict `γ` for original SF16. The theorem is a formal design target for future sound bound-aware source-pinned TT controller, **not a certification that such a controller is presently valid, faster or stronger**.
