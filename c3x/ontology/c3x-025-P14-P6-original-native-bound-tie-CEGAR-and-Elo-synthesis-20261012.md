## 3. A second genuine source-sound theorem: RootMove stable lexicographic operation
Read **original `src/search.h`** `RootMove::operator<`:
`return m.score != score ? m.score < score : m.previousScore < previousScore;`
and **original `src/search.cpp`**:
`std::stable_sort(rootMoves.begin() + pvIdx, rootMoves.begin() + pvLast);`.
For a fixed vector undergoing that exact source sort, comparator order is lexicographic decreasing `(score, previousScore)`, with stable input index resolving complete tuple ties. This is an **exact operational sorting contract**. It is not proof that these fields represent fully evaluated chess values: `-VALUE_INFINITE` is a sorting sentinel and aspiration search can leave bounded/incomparable values; the considered subrange must actually correspond to the active `pvIdx..pvLast` and a noninterrupted search when asserting overall bestmove.
