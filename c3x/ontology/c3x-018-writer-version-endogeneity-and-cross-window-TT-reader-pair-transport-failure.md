## Full source diagnosis of an invalid assumption

On **31 selected source role arms**, representing **25 distinct game/physical-target/root-call pairs** (six STRICT/BROAD overlaps), the joint-gate UCI core always equalled the FIRST-only gate. Both one-call gates independently fired in source cold runs. In **29/31** role arms, the joint-gate suppressed only the FIRST source reader, **not** the selected second reader; in **2/31** both actually fired, with no categorical root flip.

A post-outcome all-sample probe/physical writer audit watched the selected **full64 position key at the second root call**, in both main and qsearch, with TT-native hit and independent 64-bit writer shadow \`(epoch, writer serial, writer key, writer depth)\`. Source [native run 37993971370](https://github.com/WhoSia/C3X/actions/runs/37993971370) **SUCCESS**; raw evidence SHA \`db5a780f463f88a87e222868a36c132aef4640020128210fb253d9a9bb323a88\`. Every one of the **29 role-arm nonrealizations** showed:

- **The later root call existed**, and the same full64 key was actually probed in that call;
- native TT probe **HIT** and the source shadow writer full64 key **matched** the queried key;
- the **physical TT cluster slot was the same**, but the **slot-local accepted-write epoch increased by exactly one**;
- the native source last writer **serial increased** (not the same physical writer);
- the TT raw **LOWER bound and static evaluation stayed identical in all 29**;
- the TT raw **search value stayed identical in 27 of 29**, and raw **search depth changed in 26 of 29**;
- exactly **26** watchers were at \`main\` and **3** at \`qsearch\`; the search alpha/beta window and root candidate remained identical across the matched before/after observed watch sites in all 29.

These counts are **role-arm**, not independent experimental sample counts: the 29 observations correspond to **23 distinct physical target/call pairs** among 16 game histories, and the remaining **2** role arms achieved both nominated TT reader contacts.

## Typed source-causal distinction

Let \`q=(K,s)\` be a TT *carrier* (full64 Zobrist key, physical slot). Let \`v=(q,e,\sigma,p)\` be a *writer version* with successful slot-local epoch e, in-process global writer serial sigma and raw payload p. Let \`r(v,c,m,\ell,\alpha,\beta)\` be a particular source TT reader at root-call handle c, candidate move m, recursive ply ell and search window.

A **static-target** actuator \`V_v\` suppresses bound-conditioned value-as-evaluation only for a **fixed** version v. But for two later readers, the version observed in a *passive* search need not be preserved after disabling an *earlier* reader:

\`v_2(do(V_v first)) != v_2(passive)\`.

Thus first-gate contact and second-gate eligibility are jointly *treatment-dependent*. The hidden assumption behind treating two passive reads as independently manipulable is **cross-arm writer-version stability**. The January audit supplies counterexamples to that assumption.

This yields an **operational nonidentification result**, not a universal mathematical theorem: a null result under fixed \`(key,slot,epoch)\` paired intervention does not identify the effect of simultaneously suppressing two *roles* if earlier treatment creates a new writer version that the second fixed gate does not match. Conversely, automatically retargeting to epoch+1 **without a new preregistered policy** changes the treatment into a dynamic role-following intervention and is not a valid rescue of failed J2–J4.

2. **Dynamic source-role policy:** preregister a physically audited *version-following* or read-site role-following TT consumer guard independent of source keys/root-call numeric IDs. Treat this as a **different causal estimand**, not an after-the-fact retargeted January test. Record all dynamically contacted writer identities, raw value and V effect; accept failure if no categorical root change.

Any new prediction needs *another engine-blind game cohort*, not resampling the January 16 or the December success case.

## Authority limitations

- Writer serial and root-call handle have only *within-process* meaning. Cross-arm equal root numbers are not invariant recursive node identities.
- The study uses original legal chess FEN with original halfmove/fullmove clocks, not full original repetition history.
- J2/J3/J4 remain prospective failures. Neither the December restricted Boolean cube nor the January adaptive epoch taxonomy establishes exclusive natural TT mediation, independent-engine transport or a universal chess positional concept relation.
