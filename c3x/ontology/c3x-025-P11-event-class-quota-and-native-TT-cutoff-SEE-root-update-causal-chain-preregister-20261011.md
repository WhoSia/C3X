**Locked before P11 native first execution, 2026-10-11.** The original C3X0.25-P8 instrument emitted the **first 256 TT writer/reader events**, giving 84 per-field writer→reader links but zero actually executed bound cutoffs within that bounded prefix; the original depth7 root candidate endpoint P9-R1 (candidate 20, score14, b1c3) passed, yet the link between them is missing. ## Registered certificates and negative boundaries
- Actual TT score cutoff event in a selective class is verified *only* at the executed source branch, not from a precursor score conversion; if no cutoff even in this new channel declare `NO_CUTOFF_WITNESS_IN_ORIGINAL_SEARCH`, not guarantee impossible.
- A SEE quiet/qsearch guard with returned false is an actual native prune/continue **at that isolated guard source**, not proof this SEE call was invoked in a descendant of any logged TT cutoff or TT writer.
- A native root candidate score update and P9 E6 final-root source candidate are actual source events, but **the presence of all three types in a single run does NOT imply a single connected causal path**. Without same actual call-stack parent edges and child-value return provenance, the output MUST be `HOLD_NO_UNIQUE_TT_SEE_PARENT_ROOT_CAUSAL_PATH`. This “triple coincidence” adversarial negative control is a first-class hypothesis.
- Traces entirely empty for a class => `NOT_OBSERVED_IN_THIS_RUN` (with bounded information); if class cap 24 exhausted => `CENSORED_AFTER_CLASS_24`. No fake negative inference.
- Original C3X0.23 SEE native branch experiments and original 2025July role fossils are NOT current per-execution parent edges.
- If native observer alters UCI/nodes (at deterministic conditions), no scientific positive; original marker remains TECHNICAL_FAIL.

## Larger theory
Engineer an **epistemic event coverage algebra**: global FIFO prefix censorship and stratified per-class source observations have different information content even when both are constrained. A stream with 256 very common writer events but no rare cutoff is not evidence about rarity of cutoff among all recursive invocations. Long-term theory needs adaptive information sampling with precommitted allocation, missingness taxonomies and a *proof-carrying* partial causal graph; “logged” ≠ “executed” when instrumentation is selective, “same time” ≠ “same ancestry”.
