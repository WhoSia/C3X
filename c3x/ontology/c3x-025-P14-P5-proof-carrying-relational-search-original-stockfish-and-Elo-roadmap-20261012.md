## A. The mathematical target: explain a choice without reconstructing all possible worlds

Given an original chess root position and fixed root candidate set A, distinguish three noninterchangeable sets: (i) H(o), all source-admissible hidden search-machine states sharing a partial observation o; (ii) K_execution = {E_u(h): h∈H(o), policy u∈U}, full original-policy-specific execution paths including root re-search, TT epoch, rule50/repetition, alpha-beta windows, search budget, tie order and candidate-updating events; (iii) K_value = {v(h,u)∈ℝ^A}, defined **only if** each candidate has a consistently comparable, rigorously specified utility meaning. The original `RootMove.score`, `uciScore`, `previousScore`, fail-soft cutoff returns, and `-VALUE_INFINITE` sentinel **do not automatically form K_value**. A finite execution trace, however complete for its chosen world, is not all H(o). Inferential gap: from some observed (policy,trace,action) to a universal property over all compatible hidden worlds. Two hidden worlds can produce the same truncated source log yet differ in an unobserved counterfactual root choice; observational trace-only inequalities cannot become source-semantic proof axioms.

**Elementary query-completeness theorem.** For *finite nonempty valid* K⊆ℝ^A, fixed A and strict preference, set `D_K(w,a)=max_{v∈K}(v_a-v_w)`. Then w is strictly optimal in **all** worlds in K iff `D_K(w,a)<0` for every a≠w. Thus reconstructing all of K is *not required for this single root-choice question*: sound **upper bounds on each challenger-minus-winner difference** suffice. Tight difference bounds are query-complete in this finite model; loose bounds remain sound but may ABSTAIN. For compact infinite K the statement with max remains valid; for arbitrary noncompact K, a strict negative sup implies robust choice but the reverse can fail without a uniform positive margin. For actual Stockfish, even the basic existence and comparability of these scores and a source-to-bound proof remains open.

**Source-semantic proof obligation:** admit a constraint only with a proof that **every** compatible original hidden state/policy world obeys it. Empirical sample means, original cp score, search window label, TT numeric early-return contact or first observed q-parent event are observational features, not such proofs. A certified upper-bound graph B with entries `B_wa≥D_K(w,a)` yields winner if every B_wa<0; otherwise abstain. Exact difference-bounds abstract domain need not reconstruct the full high-dimensional correlations of K. This shifts the technical goal from impossible full enumeration to *sound query-directed abstract interpretation* — without downplaying complete-K construction as an ambitious scientific objective.

## D. Full K ambition: what a credible source-complete research route actually entails

A complete K_execution for original Stockfish requires a precisely stated boundary: original code revision, root legal position, NNUE weights/quantization, transposition hash contents and replacement generation/age, search-history/move-order data, rule50 and repetition, castling/ep metadata, frame state and alpha-beta/re-search state, clock and node budget and exact deterministic tie order. Fix Threads=1 first. A truly finite bounded machine has finitely many admissible states and search traces in principle, but complete enumeration is combinatorially huge. Candidate score values from different aspiration windows are not automatically common semantic utilities.

**Composable path:** (1) define source-state operational semantics for qscore bounded return, TT replacement/epoch and actual root aspiration loop; (2) abstract it with provenance-carrying difference-constraint graphs or more expressive relational domains; (3) give a refinement/simulation proof from original source transitions to the abstract transformer, with explicit TT aging, mate/draw/repetition/50move and search depth restrictions; (4) implement counterexample-guided abstraction refinement (CEGAR): for a failed candidate certificate, ask for the precise adversarial challenger world, run an independent source/lawful recomputation to validate or refute it, and refine only **sound** edges; (5) aim for a machine-checkable Lean/Rust certificate of the source-to-abstract correspondence, not only a collection of CI logs. **Full K remains an ambitious research branch** even though robust winner query may admit a smaller sufficient abstraction.

## E. Real chess engine invention and the Elo bar

Design prospect: **Proof-Carrying Transposition Search / Explainable Stockfish**. A production controller should use the original engine and full legality semantics by default. Only when independently sound source-derived challenger-gap certificates hold would it modify search allocation, target a rival for precise re-search, change permissible TT hint scheduling or cache read/write policy under separately proven operational contracts. Soundness of one winner at one depth does not imply equal total chess strength; *avoiding unnecessary search can reallocate compute to deeper searches*, which is only a hypothesis until clock-matched experiments.

Evidence ladder:
- **I. Explanation validity:** human-comprehensible contrast supported by original C++ source and independently checkable proof obligations, otherwise explicit ABSTAIN.
- **II. Engine semantics / safety:** no illegal move, changed TT bound/mate scoring mistake, 50-move/repetition/tablebase conflict, unexpected PV/score drift outside contract; source-verified integration, original vs candidate parity on protected cases.
- **III. Fixed-resource efficiency:** equal CPU, cores, binary flags, NNUE, threads, hash, position/time budgets; report median runtime/knps/nodes/candidate search costs with variance. Fewer nodes alone is not speed.
- **IV. Game strength:** pre-registered thousands of games or sequential stop rule, color-swapped paired openings, equal hardware/time, seeded opponent mix, draw-aware match scoring, SPRT or clearly derived confidence intervals, no source leakage or repeated optimization against the holdout. Report estimated ΔElo and uncertainty; **no measured Elo gains in P14-P5**.
