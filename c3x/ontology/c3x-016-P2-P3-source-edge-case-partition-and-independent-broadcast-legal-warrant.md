## 1. Why partition an engine behavior into cases?

A scientific partition is warranted not because names, scores or winning moves differ, but because **a source-observable operator state changes the set of counterfactual actions we can identify**. For one frozen game history and source build, the typed *opportunity* is

\[
e=(K,S,W_{\rm seq},W_{\rm bound},W_{\rm depth},R_{\rm frame},R_{\alpha\beta},C_{\rm contact}),
\]

where K is the actual 64-bit TT position key; S the physical slot; W an observed writer generation; R the original source reader; C actual contact/exposure (which is not always equivalent to treatment assignment). Human tactic labels, categorical final root moves, and source search-node states are separate fields.

**Case split admissibility rule:**
1. Predeclare its minimal source-level distinguishing witness before reading the NEW arm outcomes: in-check qsearch vs stand-pat, stored-value vs recomputed-value preservation, qualified bound/depth versus source guard not taken, exact writer generation live versus overwritten/missing, or different root candidate contact/order. Reject a split based only on final root move/score.
2. A useful split predicts *a different falsifying intervention* or an actual change in observable treatment contact. If both subtypes make all the same exposure and effect predictions, do not multiply them for taxonomy's sake.
3. Preserve every preassigned root and arm, even when the source operator does NOT fire; otherwise conditioning on post-treatment source contact selects the outcome and destroys the 2×2 randomization-like interpretation.
4. Keep outcome changes on distinct axes: categorical root move Y, score/bound V, nodes N, first root child return event, first stored root candidate score update, first changed candidate order, aspiration/PV. Do not assign one universal scalar progress score.
5. Separate **controlled intervention**, **natural causal mediator** and **source event chronological provenance**. Suppressing a writer changes downstream search history; usual natural indirect-effect identifiability assumptions are not satisfied by the factorial alone.
